# Test data

`ironcrypto-controls-0.2.23.json` is the unmodified output of
`ic ontology controls --json` from IronCrypto's `ic-cli` 0.2.23
(schema `ironcrypto-controls/1`). It is IronCrypto's statement about itself at
that version, kept here as a fixture; it is not maintained in this repository.

`ipg-controls-0.2.0.json` is IronPrivacyGuard's `docs/controls.json` at
commit `6596848`, unmodified: IPG's statement about itself, kept here as a
fixture and not maintained in this repository.

`ironkeys-controls-0.1.2.json` is IronKeys' `docs/controls.json` at 0.1.2,
unmodified, kept here on the same terms.

`ironsocketlayer-controls-0.5.0.json` is IronSocketLayer's
`docs/controls.json` at commit `09bf224` (version 0.5.0), unmodified, kept here
on the same terms.

`example-controls.json` is a fictional project's mappings in the shared form
(schema `ironsecurity-controls/1`), written for the reader's tests. It
describes no real project.
