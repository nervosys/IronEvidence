`ic ontology controls --json` from IronCrypto's `ic-cli` 0.2.23
(schema `ironcrypto-controls/1`). It is IronCrypto's statement about itself at
that version, kept here as a fixture; it is not maintained in this repository.

commit `6596848`, unmodified: IPG's statement about itself, kept here as a
fixture and not maintained in this repository.

(schema `ironsecurity-controls/1`), written for the reader's tests. It
describes no real project.
